Topic 1: Higher Order Function
Higher Order Function na enna?
         Oru function innoru function-a argument-aa receive pannina 
         illa oru function-a return pannina, adhu Higher Order Function.

Interview definition 🔥
    “A higher-order function is a function that takes another 
     function as an argument or returns a function.”

example:
      function greet(name) {
    return "Hello " + name;
   }

    function processUser(callback) {
    console.log(callback("Arun"));
   }

processUser(greet);

** Function returning another function
    Oru function innoru function-a return pannina, adhuvum Higher Order Function.

ex:
   function outer() {
    function inner() {
        console.log("Hello");
    }

    return inner;
    }
    let result = outer();

    result();

Interview-la short-aa:

A Higher Order Function can either receive a function as an argument or return a function.


Closure na enna?

Oru inner function, adha create panna outer function-oda
 variables-a remember pannina, adhu Closure.

 Example:

function outer() {
    let count = 0;

    function inner() {
        count++;
        console.log(count);
    }

    return inner;
}

let counter = outer();

counter(); // 1
counter(); // 2
counter(); // 3

Interview-la short answer:

Closure allows a function to remember and access variables from its 
outer scope even after the outer function has finished executing.
